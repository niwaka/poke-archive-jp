# poke-archive-jp

日本語対応のポケモン全国図鑑Webアプリです。

## 🌐 公開サイト

**[ポケモン全国図鑑を開く](https://poke-archive-jp-berlintree999-2923s-projects.vercel.app)**

URL: https://poke-archive-jp-berlintree999-2923s-projects.vercel.app

## 機能

- 日本語名・英語名・図鑑番号で検索
- タイプ・世代別フィルター
- ポケモン詳細、種族値、特性、進化情報
- お気に入り登録（ブラウザ内に保存）
- スマートフォン対応

## データ

[PokéAPI](https://pokeapi.co/) と [veekun Pokédex](https://github.com/veekun/pokedex) を利用しています。非公式のファン制作アプリです。
